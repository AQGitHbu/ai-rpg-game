# AI RPG 角色属性与战斗规则 MVP Spec v0.1

> 本文仅定义第一版 MVP 战斗所必需的角色属性、伤害公式与回合规则。
> 原则：**尽可能简单、题材无关、规则确定、方便后续扩展。**

## 1. 设计原则

第一版战斗系统采用统一规则，不针对武侠、仙侠、都市、西幻等题材设计不同的底层数值体系。

题材差异主要由以下内容表现：

* 技能名称
* 技能描述
* 战斗动画 / 特效
* 武器与装备表现
* 敌人与角色设定

因此 MVP 不区分：

* 力量 / 敏捷 / 体质等基础属性
* 物理攻击 / 法术攻击
* 物理防御 / 法术防御
* 元素攻击 / 元素抗性
* 命中 / 闪避
* 暴击 / 暴击抵抗
* 暴击伤害 / 暴伤减免

这些均暂不进入 MVP。

---

## 2. 角色战斗属性

每个可参与战斗的角色只有以下 **5 个核心属性**：

| 属性  | 标识  | 作用                |
| --- | --- | ----------------- |
| 生命值 | HP  | 降至 0 时角色死亡/失去战斗能力 |
| 能量值 | MP  | 使用技能时消耗           |
| 攻击  | ATK | 决定造成伤害的基础能力       |
| 防御  | DEF | 降低受到的伤害           |
| 速度  | SPD | 决定每回合行动顺序         |

玩家、伙伴、NPC、普通敌人、Boss统一使用这套属性结构。

不存在额外的「力量 → 攻击力」等二次转换。

例如：

```text
角色
HP: 500
MP: 100
ATK: 80
DEF: 50
SPD: 60
```

---

## 3. 基础伤害公式

MVP采用比例型伤害公式：

```text
基础伤害 = ATK × ATK / (ATK + DEF)
```

其中：

```text
ATK = 攻击者攻击力
DEF = 被攻击者防御力
```

例如：

```text
攻击者 ATK = 100
防御者 DEF = 100

伤害
= 100 × 100 / (100 + 100)
= 50
```

该公式作为整个战斗系统的基础伤害模型。

技能在此基础上增加技能倍率：

```text
技能伤害
= 基础伤害 × 技能倍率
```

例如：

```text
基础伤害 = 50
技能倍率 = 1.5

最终伤害 = 75
```

MVP暂不加入随机伤害浮动、暴击、元素克制等额外计算。

## 4. 回合制规则

采用**固定轮次回合制**。

每一个完整回合中：

> 所有仍然存活的角色原则上各行动一次。

速度只决定**行动先后顺序**，不会让高速角色在同一个正常回合中天然行动两次。

### 回合开始

读取所有存活角色当前 SPD：

```text
角色A SPD 100
敌人A SPD 80
角色B SPD 60
敌人B SPD 40
```

本回合行动顺序：

```text
角色A
↓
敌人A
↓
角色B
↓
敌人B
```

所有角色行动完成后，本回合结束。

下一回合重新计算行动顺序。

---

## 5. 角色可执行行动

角色行动时，MVP只提供四种基础 Action：

```text
普通攻击
技能
道具
防御
```

### 普通攻击

选择一个合法敌方目标。

按照基础伤害公式计算伤害。

```text
伤害 = ATK × ATK / (ATK + DEF)
```

### 技能

选择技能以及合法目标。

首先检查：

```text
MP >= 技能MP消耗
```

满足条件：

```text
扣除MP
→ 执行技能
→ 计算技能效果
```

MP不足则该技能不可使用。

### 道具

使用当前允许在战斗中使用的道具。

具体道具效果由道具系统定义。

### 防御

角色放弃本次攻击行为，进入防御状态。

MVP规则：

```text
受到伤害 × 50%
```

防御状态持续到：

```text
该角色下一次行动开始
```

随后自动解除。

---

## 6. HP与死亡

任何伤害结算后立即更新目标HP：

```text
HP = HP - 最终伤害
```

最低：

```text
HP = 0
```

当：

```text
HP <= 0
```

角色立即进入死亡 / 失去战斗能力状态。

死亡角色：

* 不可以继续行动
* 不可以成为普通行动主体
* 如果本回合尚未行动，直接从行动队列中跳过

MVP不加入濒死、临死反击等特殊规则。

---

## 7. Buff / Debuff

MVP允许技能产生简单的 Buff / Debuff。

例如：

```text
攻击 +20%
持续 3 回合
```

效果在技能成功释放后**立即生效**。

持续时间按照效果拥有者自己的行动计算。

角色每次行动结束：

```text
剩余持续回合 -1
```

当：

```text
剩余回合 = 0
```

效果移除。

MVP暂不设计复杂的 Buff 叠加、覆盖、优先级体系。

---

## 8. 战斗胜负

默认胜利条件：

```text
敌方所有角色 HP = 0
→ 战斗胜利
```

默认失败条件：

```text
我方所有角色 HP = 0
→ 战斗失败
```

剧情特殊战斗未来可以扩展其他胜负条件，但不属于 MVP 基础规则。

---

## 9. 单回合完整流程

```text
回合开始
    ↓
获取所有存活角色
    ↓
按照 SPD 从高到低排序
    ↓
生成行动队列
    ↓
轮到角色行动
    ↓
角色是否存活？
 ┌──否──→ 跳过
 │
 是
 ↓
选择 Action
    ↓
普通攻击 / 技能 / 道具 / 防御
    ↓
执行效果
    ↓
结算伤害 / 回复 / Buff / Debuff
    ↓
检查死亡
    ↓
检查战斗胜负
    ↓
未结束
    ↓
处理该角色 Buff / Debuff 持续时间
    ↓
下一角色
    ↓
所有角色行动完成
    ↓
本回合结束
    ↓
进入下一回合
```

## 10. MVP最终范围

第一版只实现：

**5项属性**

```text
HP
MP
ATK
DEF
SPD
```

**1套伤害公式**

```text
Damage = ATK × ATK / (ATK + DEF)
```

**4种基础行动**

```text
普通攻击
技能
道具
防御
```

**1种回合机制**

```text
每回合所有存活角色行动一次
SPD决定行动顺序
```

整个 MVP 战斗系统优先保证：

> **规则少、容易理解、容易实现、容易调数值，并给未来的技能、装备、状态和 AI 动态内容留下扩展空间。**
