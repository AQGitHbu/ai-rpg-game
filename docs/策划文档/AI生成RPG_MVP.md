# AI 生成 RPG MVP

> 本文是当前正式的玩家规则基线，只描述产品行为和边界。运行时实现见[Agent 文档索引](../Agent文档索引.md)。

## 1. 产品定义

玩家选择一种游戏类型，填写角色资料、世界背景和故事开端，并选择短篇或中篇。系统为本局生成一个可完成的开局切片：世界前提、玩家角色、序幕、一个起始地点、一名开场 NPC、第一条主线目标、内容预算和两个抽象结局方向。

开局只展示已经成立的内容，不预先展示完整的未来地点、NPC、任务、物品、敌人或具体结局。后续内容在剧情需要且预算允许时逐步出现，并由规则确认可达性和主线推进。

生产环境的 AI 生成失败会显示稳定失败状态，保留已提交的规则结果，并允许重试同一任务。确定性内容只用于明确的离线 fixture 与回放验收。

## 2. 新游戏输入

| 输入 | 当前要求 |
|---|---|
| 游戏类型 | 武侠、仙侠、奇幻、科幻、都市、历史架空、末日 |
| 角色名字 | 必填，2–20 字符 |
| 身份/职业 | 必填，2–80 字符 |
| 角色基础信息 | 选填，最多 300 字符 |
| 性格倾向 | 0–3 个不重复标签 |
| 世界观背景 | 必填，20–500 字符 |
| 故事开端 | 必填，20–300 字符 |
| 叙事风格 | 简洁、小说化、电影化 |
| 内容强度 | 普通、黑暗 |
| 时长 | 短篇或中篇 |

输入去除首尾空白后校验长度。背景和愿望不会直接授予属性、神器、隐藏事实或已完成任务；性格与内容强度影响叙事表达，不改变战斗数值或行动合法性。类型约束世界观与命名，具体内容由生成审批确定。

## 3. 内容预算与范围

短篇为 3 幕，地点软顶 8、NPC 软顶 10；中篇为 5 幕，地点软顶 14、NPC 软顶 16。两档硬上限均为地点 40、NPC 30。实际剧情、支线、物品和敌人数量还受可完成性与当前主线需要约束。

当前正式产品只支持短篇和中篇。长篇或开放式游玩需要先具备分段事件记录、快照、游标、归档、迁移和确定性回放能力，产品不承诺无限时长或无限记忆。

## 4. 开局与世界推进

开局包含一个地点、一名 NPC、一条活动主线及其必要事实。新地点、NPC、任务、物品、敌人和结局内容只能在获得批准后逐步释放；已生成但尚未释放的内容不会出现在地图、任务、场景或 NPC 可见信息中。

开局成功时序幕与首个可交互场景已经准备好；开始冒险的确认只结束序幕，不发起第二次 AI 请求。后续生成由开局或正式焦点 NPC 的固定选择/自由输入触发；移动、取物、战斗开始与结算等已确定边界消费已批准的连续内容或规则反馈。

## 5. 玩家行动与反馈

玩家操作分为对话、旅行、物品交互、主动开战和战斗内操作。对话承载立场与关系，旅行选择目的地，物品交互决定场景物品的拾取与向 NPC 交付；终幕立场属于对话，序幕确认与关闭对白属于阅读导航。服务端提供的合法选择才可提交；非法或过期选择不会改变状态，并说明原因。

场景直接展示已经可见的环境与线索，不提供泛化的“探索一下”或独立调查方式按钮。事实由规则在正确的任务边界确认，目标建筑的进入承接该处内容。NPC 对话保持有实际后果的两个回应，不用“先观察四周”凑成第二个选项。

拾取只能取得当前地点存在且尚未拥有的物品；同一物品只能取得一次。物品有两种获取方式：点击场景物品拾取，或在 NPC 对话达到规则约定的赠予节点时由 NPC 交给玩家。NPC 给予的物品直接进入背包并显示获得反馈，不再出现在场景中要求二次拾取。向 NPC 交付物品仍由玩家明确选择，不从对白或自由输入推断玩家已同意赠送。旅行与开战也保留明确选择。移动、任务、物品和战斗的结构化结果会影响后续主线、关系、知识、资源和结局。

## 6. NPC 对话、知识与记忆

普通焦点 NPC 场景同时提供两个语义不同的固定选择和一个自由输入入口。两种输入都经过同一规则回合，成功提交会产生独立回合并推进关系、记忆或主线。打开已准备的对白与普通建筑只导航；目标建筑可能在进入时自动确认调查事实，缺少正式对白的目标 NPC 需要提交交谈入口。

NPC 只能依据自己的公开资料、已知或怀疑事实、关系态度和最近结构化互动回应，不能因为 AI 看到了更完整的世界信息而泄露秘密。玩家自由输入不能直接获得未知事实、奖励或任务捷径。

场景收尾可能给出唯一的下一步入口：前往下一地点或继续目标时由该入口承接；同地点 NPC 交接由关闭旧对话并进入目标建筑承接。它们不额外制造一次闲聊回合。最终结局对话由规则提供支持/质疑立场，结局阶段不开放自由输入。

系统保留已发生事件、NPC 的有向关系和允许传播的知识；人格锚点在创建时确定。记忆检索承接与当前目标有关的旧事，当前事实优先于历史摘要。

玩家本轮原文用于生成当前回应，不作为长期记忆或后续历史回放；专用 AI 审计可保存原文，具体开关与范围见[AI 文本审计](../agent/AI文本审计.md)。

## 7. 战斗与结局

战斗按速度顺序结算攻击、技能、防御与撤退，生命、能量消耗、伤害、胜负和任务结果由规则决定。活跃战斗回合不等待 AI；战败或撤退恢复战前检查点，玩家可重新挑战，失败战斗的关系与记忆变化不会成为永久后果。胜利推进击败目标与相关任务，终幕以规则提供的支持/质疑立场和既有条件确定结局。

当前没有装备数值、物品使用、交易、经验成长或随机掉落经济。

## 8. AI 生成与失败

生成与知识权限的分工见[运行时 AI 职责](运行时AI角色职责与生成规则.md)。
传输、超时、空响应、格式、引用、类型、预算、知识边界或审批失败都会进入可见失败态。系统不使用 deterministic、fixture、模板台词或默认问候冒充生产成功；规则反馈可以正常展示，但会明确属于规则结果。失败任务可由玩家手动重试，普通检查不会偷偷重复调用 AI。

## 9. 可重放与差异

在固定的已批准生成内容或离线 fixture 下，相同 seed、行动序列和规则版本可重放规则结果；不同选择应形成结构化分化并影响结局。相同 seed 不保证两次真实 AI 创建得到相同实体或文案，生成结果仍须经过审批。完整无 AI 旅程只代表显式 offline fixture/replay 的验收能力，不代表生产 AI 失败时仍会自动通关。
