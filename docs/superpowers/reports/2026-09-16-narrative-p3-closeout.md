## 实施证据

### 匠人材料复用

`src/game/application/testing/narrativeP3CraftJourney.test.ts` 构造独立陶工作坊初态，通过正式后果绑定审批、互动提案安装和 `resolveTurn` 验证：私下筛检泥样→告知助手，窑师保持不知情→实际告知窑师，目标完成→指导试烧成为可执行方法→实际试烧产生唯一发现。未开放方法不可提前执行，重复操作不重复产生目标或发现；没有物品递送、信筒或原故事人名依赖。

该片段发现并修复了空目标条件契约不一致：Plan 允许空 completeWhen/blockWhen 不触发对应状态，审批和 Entity 原先拒绝。两处校验已对齐；显式空调查 requirements 同样按无前提处理，任务完成与合作的非空约束保持。相关 7 个文件共 145 项测试通过，类型检查通过；独立复核的规范与质量两项通过。这是正式规则复用证据，完整 SQLite/UI 故事另行验证。

### B 披露后果

`f12daf22` 将当前场景的实际 NPC 听众、知识事件及目标/Quest 后果接入同候选编译、审阅与最终单次 CAS。未来场景不授知，失败候选不落知识和目标；幕末披露必须提供推进后所需的合法内容。普通目标、幕末目标、失败后重试和并发发布均有正式 SQLite 回归。

独立复核发现同场转述绕过传播权限、目标完成后重复绑定误拒两处问题，`3687dde1` 改为逐句重建面向实际听众的权限，以及允许已安装的相同绑定幂等重验。全量检查还发现当前表达式预检误用终局的零选项约束，导致 P2 故事回归；已修复并保留真实选项后续校验。限定 280 项测试和未改写的 P2 完整故事 5 项通过；最终限定复核的规范与质量均通过，独立重跑原两条复现均已转绿。

### 完整故事回访

用户已确认允许“玩家在外取得、被旧 NPC 已批准任务/合作条件明确引用的新证据”触发受控回访。`44d66ec2` 接通规则和完整双路故事，`5dc0dcd9` 修正回访当前 NPC 别名不能继承未来返程 NPC。关联仍要求实际可见来源、已访问地点与最后展示事件水位，不自动给旧 NPC 授知。

私下故事实际事件顺序为离场、调查、回访、告知、目标变化、核验、返程、交付。告知前同时核对 Entity 知识与 NPC 观察者投影，均不知情；告知后的 player_told 来源精确引用真实分享事件。返程经 raw `objective_return` 编译、解析、审批与 CAS，只准备已访问相邻的未完成交谈目标，实际移动仍由玩家选择。公开路线保持不同调查见证与合作准入，两路均正常终局且交付一次，调查后重载记录一致。

### 有界 live/UI

新增薄 UI 执行入口 `npm run journey:narrative:p3:ui`，复用现有 Next 页面和生产 entry，私下路线通过实际浏览器提交 driver 当步选中的正式 token/自由策略，公开路线从同一初态通过 API 完成。原 driver 保留 Action 身份、调用预算、绝对截止时间和 tape，不增加第三条路线。执行器选择在初始化前以协议/代码指纹登记，禁止在 UI 重新创建、清档或手动续预算。

修正私下策略必须早于调查、重载必须在调查之后、完成判定须对应真实证据的分享/目标/核验与受控回访。UI 中途刷新比较正式状态哈希，终局刷新不能替代中途刷新。31 项相关 Node 测试通过；独立复核提出的启动清理、终局刷新误判、关闭异常跳过结算三项已修复并通过限定复核。

本轮尚未登记或执行真实批次，也没有实际 UI 通过证据。完整故事回访已通过，最终检查通过，接下来冻结代码执行 live/UI；没有通过标记、追加抽样或文学修稿替代这些证据。
