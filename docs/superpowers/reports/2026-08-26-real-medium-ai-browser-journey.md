# 2026-08-26 真实中篇 AI 浏览器验收

## 结论

使用用户指定的 Chrome 完成两局真实 API 中篇游戏：首局武侠到达结局；重启后的奇幻局从开局走到“潮汐归位·守望之光”，共 17 回合。玩家可见剧情均来自 API 通过结构审批后的生成内容，没有显示 deterministic、fixture、默认台词或 fallback。

审计运行目录为 /tmp/ai-rpg-real-medium-audit-20260826/real-medium-ai-20260826/events.jsonl。

- story_text.source：29 条，全部为 generated。
- 真实生成链路：opening 2 次、scene performance 38 次、world evolution 35 次。
- API 曾多次给出可解析但不可审批的世界增量；游戏保留原 job、显示失败态并只允许“重试生成回应”。未写入任何备用剧情。

## 浏览器发现与修复

1. 建筑名称含“榜”时被错误归类为酒馆，造成入口语义错误。
2. 场景旁注层遮住可拾取物品热点。
3. 幕边界在没有普通目标时把玩家留在“暂无线索”。
4. 终局探索 token 未进入服务端 choice map，且最终 NPC 对话可能不以正式 focus 页面呈现。
5. API 将已在场角色重复声明为 newNpc，或在共享 events 预算满额后继续给出可选事实或物品，导致 unreachable_objective 或 budget_exceeded 的重复格式失败。

修复采用规则、Prompt 与结构归一化：续幕必须给出从当前地点可达的新世界地点；预算满额时仅丢弃不可物化的可选增量；与既有角色重名的“新增角色”只移除该重复字段。均不合成、替换或回退剧情正文。

## 复验

修复后，在原失败保存点点击 UI 的“重试生成回应”，真实 API 生成的“潮汐之心祭坛”立即成为可达地图节点；随后完成最终抉择并进入结局页。此过程验证了失败状态可恢复、跨幕可达、最终抉择与结局展示均连续可用。
