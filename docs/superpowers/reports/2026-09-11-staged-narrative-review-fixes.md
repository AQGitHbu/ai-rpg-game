# 四模块叙事 review 修复验收

## 范围与结论

在 staged-narrative-generation worktree 修复披露认定、条件权限投影、选项依赖与合法性、初始化恢复及租约截止边界。保留四类生成器与整包原子发布，不强制分支切换地点，不新增玩法。

新增知识对白在结构审批后增加独立语义审核，只有 pass 才允许下游使用；审核拒绝、不可判定、缺失能力或服务失败均不能发布。凭据绑定实际正文、单元和授权请求，恢复/发布重验。审核是额外请求，不是第五个生成器，也不扩大任务预算。
