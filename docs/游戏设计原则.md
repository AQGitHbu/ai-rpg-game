# RPG 游戏设计原则

> 本文档只记录 AI+RPG 特有的设计判断。跨项目共同原则见 `共同规范/共同游戏设计原则.md`。

## 如何维护本文档

- 只记录可指导多个 RPG 系统的原则，不记录单一任务细节。
- 具体玩家规则写入 `策划文档/`。
- 代码路径、测试和 import 规则写入 `游戏开发规范.md`。

## RPG 特有边界

### NPC 知识必须受结构化事实限制

NPC 只能根据其已知事实、立场、误解、所见环境和与玩家的历史互动回应；AI 不能用自然语言绕过知识边界。

### 失败应反馈后果，并尽可能推进故事

失败不能伪装成成功，也不应无解释地中断主线。失败造成的关系、时间、敌意或替代路径必须结构化保存。

### 探索内容必须服务可完成的主线

第一版的新地点、NPC、任务和道具受内容预算约束；AI 生成的内容不能无限扩张而破坏可完成性。
