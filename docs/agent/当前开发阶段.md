## Phase 5 目标与边界

- 为蓝图定义预置可取得物品的位置；初始装备不能重复取得，物品不由玩家文本或 UI 直接写入。
- 新增固定 `take_item` 意图、稳定拒绝码、`item_obtained` 事件和当前地点物品 read model/UI；同一物品只能取得一次。
- 任务 reconciliation 以背包事实满足 `obtain_item`；完成第二阶段主线并解锁第三阶段，保持一次 revision CAS 写入与刷新恢复。
- 不实现 `use_item`、给予/交易、装备效果、奖励数值、战斗、`defeat_enemy`、结局、隐藏地点发现、自由输入、AI 或 shared package 变更。
