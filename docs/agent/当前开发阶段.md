## 阶段目标

- 规则事件账本保持唯一事实源；纯 reducer 将其压缩成有界、持久化的剧情记忆，旧存档缺失该字段安全回退。
- 每个 ready narrative scene 与 `narrative_scene_presented` 结构事件和 memory 同一次 CAS 保存，绝不保存 AI prose、token 或 actionKey。
- 内容推进器从当前主线状态导出允许的 `pacing`，director 提案超出当前节奏由规则拒绝并复用既有重试/fallback。
- director / writer / NPC 各自只接收最小连续性投影；NPC 只读自己最近接触和本次批准事实卡。
- 冒险日志提供安全的本章进展；日常完整旅程固定为离线 replay。

## Phase 11 实现事实

- `StoryMemoryState`（v1、cursor、recent≤12、npcContacts）与 `narrative_scene_presented` 事件已落地；`GameState.storyMemory` 可选，旧存档缺省经 `storyMemoryOf` 安全回退为空，零迁移。
- 纯 reducer `reconcileStoryMemory` 从 eventLedger cursor 之后归约、不变异输入、未知事件只推进 cursor；`deriveContentProgression` 按主线阶段派生 allowed pacing（1→setup/develop、2→develop/turn、3→climax、全完成→resolution、回退 setup/develop）。

- 玩家自由输入与意图解析 AI；
- 运行时新增 NPC、地点、物品、任务或修改蓝图；
- AI 写入记忆、自动总结剧情、修改数值、奖励、战斗、任务、地图、背包或结局；
- 关系数值、多 NPC 独立表演、自主日程、向量数据库或外部检索；
- streaming、SSE、AI 图片、语音和视觉描述生成；
- foundation、共享 UI 或 transport 修改。
