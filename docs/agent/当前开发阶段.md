## R5 实现事实

- **Task 22 对话记忆闭环**：`NpcInteraction` 改为 v2.1 结构化契约（turnNumber/actionId/dialogueAct/topicSummary/learnedFactIds，outcome 扩展 mixed）；玩家原文绝不进入长期 summary；`updateNpcMemory` 同 actionId 不因错误重试追加两次（CAS 失败路径零写入）、关系 clamp、历史保留最近 10 条。
- **Task 23 知识传播来源**：`FactChange` 引入封闭 `source`（scene_witness/player_told/npc_revealed/public_broadcast/faction_shared）；`propagateKnownFacts` 拒绝非法 source/不存在 fact/不在场 audience，只按显式 audience 传播，绝不自动扩散给同地点所有 met NPC；investigate 行动不再自动让当前地点所有 NPC 知晓。
- **Task 24 SceneGenerationContext 最小权限 DTO**：新增 FactCard/NpcSceneContext/PlayerSceneSummary/LocationSceneCard/BudgetSummary/LegalActionCandidate；每个 NPC context 只含自己的 known/hidden fact cards、最近规则摘要、relationship/emotion/goals、forbidden knowledge 索引；私密事实只出现在对应 NPC 自己的 hiddenFactCards，绝不进入 public/scene-visible facts。
- **Task 25 场景包审批**：`approveScenePackage` 校验旁白非空、台词 NPC 在场、NPC 不使用 forbidden fact、选项不语义重复、选项目标合法；核心非法整场 fallback（fallback 同轨审批）；`generatePendingSceneV2` 接入完整审批 + 候选事件池审批。
- **Task 26 read model 隔离**：`gameSessionViewV2` 任务 discover_fact 目标在事实未发现时只显示中性目标'发现秘密'，绝不泄漏 fact.text/FactId；NPC 对话选项只挂焦点 NPC，freeInput 仅焦点开启。
