## Phase 2 计划范围

- 建立 `createGame` application use case、SQLite server-only repository 和事务化初始存档；
- 用已有 fallback 生成器创建、校验、编译并保存蓝图与初始 `GameState`；
- 将新游戏表单接到同仓 API，展示可恢复的开场 read model；
- 支持刷新后恢复当前本地存档；失败不产生半存档。

不实现行动、战斗、NPC 对话/记忆、真实 AI 或新的共享 UI 导出。详细任务与验收以本阶段唯一 Plan 为准。

同输入 + seed + templateVersion 生成相同蓝图；三类型均通过校验且两结局可达；测试规模 12 文件 / 229 用例。
