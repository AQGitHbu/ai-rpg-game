# 当前开发阶段入口

[阶段配置](current-phase.json) 是阶段名称、状态、唯一执行 Plan、分支、worktree、入口资料和验收命令的唯一来源。查看状态运行 `npm run phase:status`；该命令只展示状态，不承担验收。

## 阅读与执行

1. 读取配置，打开 `plan` 指向的文件，先读目标、全局约束、明确边界与任务导航。
2. 只追加当前 Task 需要的 Spec 章节和系统文档；跨系统契约必须先理解，再进入局部任务。
3. 执行阶段时，从干净的主工作区 main 运行配置中的 `startCommand`，在目标 worktree 中工作。普通文档、修复或其他独立任务不启动阶段。
4. `npm run handoff:check:docs` 校验配置与执行入口；`npm run handoff:check` 还要求匹配阶段分支。系统实现事实见 [核心闭环](MVP核心闭环.md)，不从计划推定生产能力。

## 维护

阶段推进只更新 JSON 状态及 Plan 的任务/验收记录。新增系统按模板维护现状并登记索引，不将历代成果、运行链或测试成绩复制到本文。
