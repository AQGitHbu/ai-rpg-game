## 阶段目标

把已可玩的 Phase 7 地图与地点循环重组为持续的非战斗 RPG 游戏视窗：

~~~text
HUD / 信息入口 → 世界地图视窗 → 地点场景与行动栏 → 点击 NPC / 线索 / 物品
→ 独立对话或详情弹层 → 规则裁决与任务推进 → 返回地图
~~~

本阶段只改变非战斗的视觉层级与操作组织：地图和地点成为舞台，HUD、场景热点、行动栏、角色/背包/任务/日志和 NPC 对话成为可关闭的业务 UI。所有行动和规则仍复用既有实现，不新增 AI、战斗或世界内容。

## 阶段范围

- 持续 HUD 显示安全的世界、角色、地点和当前主线摘要；角色、背包、任务、日志均以可关闭业务弹层打开。
- 地图使用本地 SVG 底图与稳定节点位置；current、travelable、known、locked 的既有交互与零泄漏规则不变。
- 地点使用背景、热点和仅含当前真实可用能力的行动栏；NPC、观察、线索、物品和返回地图均可从场景内操作。
- NPC 对话、详情与规则反馈改成场景化弹层/toast，保留既有 dialogue_choice 和 action payload。
- 只使用本仓内联 SVG；零 AI 图片调用、零外部图片服务；不新增持久化字段或 state migration。
