## Agent 开始步骤

```powershell

```

该命令读取 `current-phase.json`，创建/复用目标分支及 worktree，执行 setup 和严格交接检查。需要预览时运行 `npm run phase:start -- --dry-run`。`handoff:check` 失败时不得开始编码。Phase 1 不修改 UI、数据库、AI 调用或 foundation；发现范围不足时先更新 Plan。
