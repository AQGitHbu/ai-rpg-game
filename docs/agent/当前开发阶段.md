# 当前开发阶段

> 当前阶段：Phase 13：NPC 关系与知识演化
> 状态：已实现（implemented；worktree `.worktrees/phase13-npc-relationship`，分支 `codex/phase13-npc-relationship`）

## 阶段目标

- NPC 好感度系统：单维度 `affinity`（-100 ~ +100），五档 `hostile/cold/neutral/friendly/trusted`。
- 固定选项对话（`greet`/`ask_main_quest`）在 `resolveAction` 中计算关系变化，`dialogue_choice` 分支写入 `NpcRuntimeState.relationship`。
- 自由输入对话在 `handleNpcDialogue` 中通过 `classifyDialogueTone` 纯规则语气分类（零 AI）计算关系变化，正面/负面语气分别 ±3。
- NPC 演员根据 `NpcLineContext` 中的 `relationshipTier`/`relationshipAffinity`/`relationshipSummary` 调整台词语气与态度（performer prompt 已更新）。
- `reconcileStoryMemory` 从 `npc_met.interactionKind` 推导 `lastInteractionSummary`，实现 NPC 交互记忆。
- 旧存档完全兼容：新增字段均为可选，缺省安全回退到 neutral 档位。

## 阶段范围

- domain：`RelationshipValue` 类型、`RelationshipTier` 档位、`relationshipTierOf`/`clampAffinity` 纯函数、`RELATIONSHIP_CHANGE` 常量；`NpcRuntimeState.relationship` 可选字段；`NpcMetEvent.interactionKind` 可选字段；`NpcContinuityMemory.lastInteractionSummary` 可选字段。
- gameplay：`classifyDialogueTone` 纯规则语气分类器（零 AI，关键词匹配）；`projectRelationshipSummary` 摘要投影函数。
- application：`resolveAction` dialogue_choice 分支增加 `greet`/`ask_main_quest` 关系变化计算与 `interactionKind`；`handleNpcDialogue` 自由输入路径增加 `classifyDialogueTone` 与关系变化写入；`NpcLineContext` 扩展 `relationshipTier`/`relationshipAffinity`/`relationshipSummary` 字段；`toNpcLineContext` 从 state 读取关系值注入；`reconcileStoryMemory` 从 `npc_met.interactionKind` 推导 `lastInteractionSummary`。
- server：NPC performer prompt 追加关系值引用 instruction，指导模型根据关系调整语气/态度。

## Phase 13 明确不做

- 蓝图初始关系预设（NPC 起始好感度固定为 0）。
- 关系影响任务推进（如 NPC 好感度不足拒绝提供线索）。
- 多维度关系（如信任度、恐惧度）；类型已预留但仅实现单维度。
- 关系值的可视化 UI（如好感度进度条）。
- NPC 自主日程或独立行为（如根据好感度改变所在位置）。
- AI 驱动的 NPC 记忆总结（`lastInteractionSummary` 由规则推导，非 AI 生成）。
