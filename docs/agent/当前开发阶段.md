## 阶段目标

把 Phase 6 已实现、Phase 8 尚未场景化的确定性 boss 战接入游戏主视窗：

~~~text
地点敌人热点 → 场景化战斗视窗 → 攻击 / 防御 / 撤退 → 规则裁决与反馈
→ 胜利或失败结局 / 返回非战斗地点
~~~

本阶段只提升战斗的视觉层级与交互组织：战场、敌我肖像、HP、回合、固定行动栏和反馈日志均来自既有安全 read model 与 API 结果。战斗规则、数值、存档和根路由不变。

## 阶段范围

- 使用本地 SVG 背景与敌我肖像呈现 battle-viewport；HP、敌名、回合只读自 BattleView。
- 攻击、防御、撤退组成固定行动栏，只提交既有 battle_action payload 与 revision。
- API 成功、拒绝、stale 与网络反馈显示为可访问日志；客户端不改 HP、回合或胜负。
- active battle、ending、非战斗 AdventureGameShell 的根路由保持不变；窄屏安全可用。
- 零新增规则字段、AI 调用、外部图片或共享 UI 修改。

## 明确不做

- 普通敌人、随机遭遇、技能、状态、暴击、掉落、经验、治疗、装备/物品效果、重试、同伴、交易、自由输入、AI 对话/叙事/生图；
- 战斗数值、伤害公式、任务推进、结局条件、API 协议或存档迁移。
