## 阶段目标

- NPC 对话成为叙事场景入口：`greet` 首遇 / `ask_main_quest` 与 `narrative_choice` 共用同一 pending 排队条件；重复 greet 不排队。

- 复用既有 pending + ensure 轮询恢复链路，零新增轮询代码；实现事实见 `docs/agent/NPC对话驱动叙事场景触发.md`。
