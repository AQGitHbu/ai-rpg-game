# 项目脚手架

## 系统定位

RPG 项目的 Next.js、测试、目录分层、共同规范同步和架构边界基础。

## 当前实现现状

- 主页面仅展示脚手架状态。
- 根 `AGENTS.md` 只保存文档路由与共享基础设施触发条件。
- `scripts/syncStandards.mjs` 从本地 `ai-game-foundation` bootstrap 共同规范。
- `src/dependencyBoundaries.test.ts` 守卫初始分层。

## 主要文件

- `package.json`
- `AGENTS.md`
- `scripts/doctor.mjs`
- `scripts/syncStandards.mjs`
- `src/dependencyBoundaries.test.ts`

## 主要测试

- `npm run check:standards`
- `npm run test:boundaries`
- `npm run test:fast`

## 修改注意事项

- 不要在脚手架阶段预先设计 RPG 玩法模型。
- 共享流程仅在根 AGENTS 的触发条件命中时读取。
- UI package 等到 RPG 第一次真实使用通用原语时才评估抽取。
