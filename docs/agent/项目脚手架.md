# 项目脚手架

## 职责与阅读时机

修改开发脚本、目录边界、文档门禁或处理 worktree 时阅读。应用入口 `src/app/page.tsx` 渲染 `CurrentGameScreen`；业务流程见 [核心闭环](MVP核心闭环.md)。

## 环境与分支操作

- `npm run setup` 初始化本仓环境、连接 foundation、安装依赖并检查环境；不从消费者构建公共 package。共享定位遵循 [共享流程](../共同规范/共享模块开发流程.md)。
- 中文 Git 路径显示使用本仓 `git config core.quotepath false`；解析 Git 文件路径的脚本显式传 `-c core.quotepath=false`，不依赖全局设置。
- 独立分支 worktree 位于主仓 `.worktrees/<name>`。阶段创建由 [阶段入口](当前开发阶段.md) 指引，普通任务不改阶段指针。
- 在干净 main 运行 `npm run branch:merge -- <branch>`：同时验证目标 worktree 干净，执行 fast-forward 合并并调用 `branch:finish`。不自动创建 merge commit。
- 已合并分支使用 `npm run branch:finish -- <branch>`：验证祖先关系，定位对应 worktree，委托安全清理，再执行 `git branch -d`。两个入口支持 `--dry-run`。
- `npm run worktree:remove -- <name>` 是只清理 worktree 的入口。它委托 foundation 的非递归链接解绑与 Git 清理；残留仅在登记已解除、链接已解绑并复扫零链接后受控处理。
- 清理前退出 worktree 中的 dev server、watcher 等进程。权限或链接异常时保留现场，不改用递归删除或扩大清理路径；保护约束见 [AGENTS.md](../../AGENTS.md)。

## 文档门禁

`npm run check:docs` 扫描根入口、docs 根目录的当前文档，以及 agent、策划、operations 目录；不扫描 archive、superpowers、设想、真机测试和共同规范正文。

- 阻断：本地文档链接或标题锚点失效、npm 命令不存在、当前索引引向退役资料、系统文档未被索引覆盖、阶段配置引用失效、阶段入口重新保存一份手写状态。
- 提醒：历史更新标题、超过篇幅软阈值、跨文档重复长段落、源码入口失效。提醒需人工判断，机械通过不代表事实正确。
- 当前阶段 Markdown 只链接 JSON；JSON 与 Plan 的状态组合另由 `handoff:check:docs` 验证。
- 新增文档用 Markdown 相对链接，源码入口使用仓库根路径。文档事实按 [维护约定](README.md) 原位更新。

## 代码与验证入口

| 文件 | 验证 |
|---|---|
| `scripts/checkDocs.mjs` | `npm run test:docs`：临时目录注入坏链接、退役入口和阶段漂移 |
| `scripts/checkHandoff.mjs` | `npm run test:handoff-check`：阶段策略与 worktree 一致性 |
| `scripts/removeWorktree.mjs` | `npm run test:worktree-remove`：链接保护与残留处理 |
| `scripts/finishBranch.mjs` | `npm run test:branch-finish`：仅收尾已合入分支 |
| `scripts/mergeBranch.mjs` | `npm run test:branch-merge`：干净工作区与 fast-forward |
| `src/dependencyBoundaries.test.ts` | `npm run test:boundaries`：分层、core 与 gameplay facade |

`handoff:check:docs` 与 `handoff:check` 均先运行文档检查。`npm run test:fast` 包含文档及脚本门禁、类型与依赖边界。SQLite 仓储测试在各进程独占的 OS 临时目录运行；Git Bash 管道查看测试输出时启用 pipefail，保留上游退出码。
