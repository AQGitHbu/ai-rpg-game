# 项目脚手架

## 系统定位

RPG 项目的 Next.js、测试、目录分层、共同规范同步和架构边界基础。

## 当前实现现状

- 主页面仅展示脚手架状态。
- 根 `AGENTS.md` 只保存文档路由与共享基础设施触发条件。
- `scripts/syncStandards.mjs` 从本地 `ai-game-foundation` bootstrap 共同规范。
- `scripts/removeWorktree.mjs`（`npm run worktree:remove -- <name> [--delete-branch]`）：安全删除 `.worktrees/<name>` 的唯一快捷入口——先委托受保护的 foundation 工具 `cleanupConsumerWorktree.mjs`（解绑 `.foundation` junction、解除 git 登记）；工具因 `node_modules`/`tmp` 残留报 "Directory not empty" 时，仅在四项安全前提全部通过（junction 已解绑、登记已解除、目录内链接逐个非递归解除、复扫零链接）后才清理残留；分支只用 `git branch -d` 安全删除。必须从主工作区运行，禁止直接 `git worktree remove`。
- `src/dependencyBoundaries.test.ts` 守卫初始分层。

## 主要文件

## 修改注意事项

- 不要在脚手架阶段预先设计 RPG 玩法模型。
- 共享流程仅在根 AGENTS 的触发条件命中时读取。
- UI package 等到 RPG 第一次真实使用通用原语时才评估抽取。
