# 系统文档维护

通过 [Agent 文档索引](../Agent文档索引.md) 定位系统；本目录只维护已实现的契约、入口、限制和验证方式。

- 按 [模板](template.md) 写最小必要说明。简单系统可省略流程，不用空章节凑结构。
- 规则变化原位重写；删除被替换的说明，不保留日期更新或历史版本教程。
- 源码是实现事实证据；遇到文档与代码不一致先核实，不按日期较新的一段猜测。
- 关联阅读必须说明触发条件，不要求递归读完所有链接；不重复粘贴关联系统的契约。
- 测试入口说明验证什么；某次执行结果、运行 ID 和测试数量属于报告。
- 新增、移动或删除系统文档时更新索引与当前引用，执行 `npm run check:docs`。完整维护归属见 [AGENTS.md](../../AGENTS.md)。
