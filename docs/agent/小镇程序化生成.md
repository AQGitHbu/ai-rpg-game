# 小镇程序化生成

## 系统定位

大场景地点（`LocationDefinition.scale === "town"`）在玩家进入时呈现确定性生成的小镇层（地图 → 城镇 → 建筑场景三层导航）。城镇几何由纯生成器从 `TownRuntimeState`（locationId + seed + generatorVersion + slots）确定性重建，不落地权威几何；运行时 NPC 按需绑定到剧情建筑 slot。开局候选可以携带 AI/fallback 生成的剧情建筑名，写入已绑定剧情 slot 的 `displayName`，只改变玩家看到的剧情建筑名，不改变几何、建筑类型或寻路；服务端不再用硬编码开局锚点覆盖候选。**纯生成器，无网络、无 AI 生图**。

- Plan：`docs/superpowers/plans/2026-08-11-dynamic-story-materialization-and-contextual-narrative.md`（Task 7）
- 上游设想：`docs/设想/AI驱动RPG_大地图-小镇地图-场景与小镇生成方案_v0.1.md`（历史设想；当前实现以本页为准）

## 当前规则摘要

`generateTown` 管线（固定算法参数；同 seed 深度相等）：

1. **确定性规划**：`createFallbackTownPlan(seed)` 产出确定性语义规划（四区域 + 必备剧情建筑 + well 地标 + 网格），seed 只影响 theme/地形朝向/区域方位等风味字段，不调 AI。
2. **五阶段生成**：terrain → anchors → roads → blocks/plots → buildings，每阶段用 `createTownRng(effectiveSeed + ":" + 阶段名)` 独立派生随机流。
3. **验证**（`validateTownDraft`，collect-all）：道路图节点从主城门 BFS 全可达；建筑入口在 footprint 边界、门前格为道路且道路层可达主城门；footprint 两两不相交、不压道路/水域/城外；非 reserved 地块临街 ≥ 2 格。
4. **修复与重试**：建筑类 issue 按「换入口方向 → 开 1–3 格门前巷道 → 舍弃泛化建筑」次序修复；剧情建筑不可舍弃。修复预算按验证轮次计 ≤ 20 轮；无解时以 `hashTownSeed(seed + "#retry" + n)` 派生 seed 重跑整镇 ≤ 3 次；全败抛 `TownGenerationError`。
5. **确定性**：生成器为纯函数，随机只来自 seed（FNV-1a + mulberry32，见 `townRandom.ts`）；无 `Math.random` / `Date` / IO / env。

网格合法域 24–40（方形），默认 32×32；生成器版本 `TOWN_GENERATOR_VERSION = "town-gen-0.1.0"`。

## 运行时 slot 层（Task 7）

- **开局预分配**：地点为 `scale: "town"` 时，开局编译（`compileOpeningGenerationCandidate`）调用 `createTownRuntime({ locationId, seed: townSeedFor(generationSeed, locationId), openingBuildingName })` 生成稳定几何，并把全部 `storyRequired` 建筑映射为**未绑定**的剧情建筑 slot（`TownBuildingSlot[]`，`boundNpcId: null`）。只将当前开局候选携带的剧情建筑展示名写入 slot_0，不生成任何未来 NPC 名称。
- **开场 NPC 绑定**：开局焦点 NPC `npc_0` 绑定 slot_0；`bindNpcToTownSlot` 只改 slot 的 `boundNpcId`，几何与既有 buildingId 不变。
- **运行时绑定**：后续世界演化把新 NPC 具象化进该城镇时，绑定第一个空闲 slot。
- **确定性重建**：权威几何不入存档；`generateTown({ seed })` 在 read model 中按需重建，存档只落 `TownRuntimeState`。
- **读模型**（`buildTownView`）：只暴露快照、展示标签与已绑定可交互建筑条目（`interactiveBuildings`）；条目通过 `isCurrentFocus` 标记真正的当前主线人物，普通建筑不冒充“当前剧情”；满槽时当前目标也会投影到一个可达剧情建筑入口，不暴露“临时会面”旁路；不暴露 seed、空闲 slot、生成器内部、隐藏 NPC 或未批准地点。未绑定剧情建筑渲染为「未探索」占位，不展示真实名称。
- **动态建筑归属**：世界演化的 `town_building` 提案复用预分配 slot，不创建同级世界地图地点；审批要求当前城镇仍有空闲 slot，物化时写入 NPC 绑定和建筑展示名。真正独立、需要旅行的地点才使用 `placement: "world"`。
- **无 town 路由**：城镇层是 application/gameplay 纯工作，不存在 `/api/game/town/ensure` 或任何 town 生产 API 路由。

## 领域类型与生成器

- `src/game/domain/townState.ts` — `TownRuntimeState` / `TownBuildingSlot` / 瓦片与快照类型 / `TOWN_GENERATOR_VERSION` / 网格常量 / `tileIndex`。
- `src/game/gameplay/rpg/town/index.ts` — 生成器公共门面（唯一合法导入口）。
- `src/game/gameplay/rpg/town/townRandom.ts` — FNV-1a + mulberry32 确定性随机源、`hashTownSeed`。
- `src/game/gameplay/rpg/town/fallbackTownPlan.ts` — 确定性 fallback 语义规划。
- `src/game/gameplay/rpg/town/terrain.ts` / `anchors.ts` / `roads.ts` / `blocks.ts` / `buildings.ts` — 五阶段实现。
- `src/game/gameplay/rpg/town/validateTown.ts` — collect-all 验证 + `TownDraft` / `TownValidationIssue`。
- `src/game/gameplay/rpg/town/generateTown.ts` — 编排 + 修复/重试循环 + `TownGenerationError`。
- `src/game/gameplay/rpg/town/createTownRuntime.ts` / `bindNpcToTownSlot.ts` — 运行时 slot 预分配与 NPC 绑定。
- `src/game/application/townView.ts` — `buildTownView` 投影门面。

## UI

- `src/components/TownLayerScreen.tsx` — 城镇层（第三层入口）：逻辑地图 + 可进入建筑交互入口；未选中时侧栏只给地图提示，点击高亮建筑后显示建筑名/NPC 名/进入按钮；仅焦点入口显示“当前剧情”，不再常驻临时会面面板；返回地图按钮。
- `src/components/town/TownMapSvg.tsx` — 确定性 SVG 逻辑地图（每格 12px rect 按 TileType 着色；从 `public/assets/town/*.webp` 按 8 种 `buildingType` 叠加历史静态预设屋顶图；只有已绑定剧情建筑可点击/键盘可达；`storyRequired` 高亮；未绑定剧情建筑用不泄漏类型的「未探索」灰块且不加载对应图片）。图片是 `pointer-events: none` 的表现层，不改变 footprint、寻路或规则。

## 修改注意事项

- **生成器必须保持纯函数**：随机只能来自 seed 派生的 `TownRng`，禁止 `Math.random` / `Date` / IO / env；任何算法或参数改动都会改变同 seed 输出，必须先跑 1000 seed 批量回归，且**断言失败先修生成器，不放宽断言**。
- **算法/参数演进时提升 `TOWN_GENERATOR_VERSION`**，便于快照回归钉值。
- town 内部模块只能经 `@/game/gameplay/rpg/town` 门面消费；新导出需同步考虑 `dependencyBoundaries.test.ts`。
- 不得恢复旧 `/api/game/town/ensure`、`town-plan-v1` AI 契约、`townGeneration` pending 态或 `TownSemanticPlan` AI 提案管线；城镇层保持确定性 application/gameplay 工作。
- 保持三层导航为纯 UI 导航：不新增 `enter_building` 意图，不改位置指针粒度。
