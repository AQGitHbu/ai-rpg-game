# 小镇程序化生成

## 系统定位

验证「语义规划 → 确定性程序生成 → 验证/修复」的小镇生成管线（`/town-demo` 页面独立演示该纯生成器）。**已接入游戏主循环**（分支 `codex/town-generation-demo`）：大场景地点（`LocationDefinition.scale === "town"`）在首次进入时懒生成小镇，存档只落 `TownSemanticPlan + seed + generatorVersion`（`GameState.towns`），`TownSnapshot` 由 `generateTown` 在 read model 中确定性重建，存档小、天然兼容、与全仓确定性纪律一致。小场景地点保持两层 map→scene，大场景为三层 map→town→scene。

**用户硬约束：AI 生图未接入。** 建筑插图一律为程序生成的 SVG 占位图；application 层已预留 `TownIllustrationSource` port（契约 `town-assets-v0`），生产实现恒返回 `{ status: "not_requested" }`，无任何网络调用。

## 当前规则摘要

RFP-Town 管线（`generateTown` 编排，固定算法参数见 Spec §5 参数表）：

1. **语义规划**：`input.plan` 缺省时由 `createFallbackTownPlan(seed)` 产出确定性规划（结构恒定：四区域 + 3 剧情建筑 tavern/blacksmith/house + well 地标 + 32×32 网格；seed 只影响 theme/地形朝向/区域方位等风味字段，不调 AI）。
2. **五阶段生成**：terrain → anchors → roads → blocks/plots → buildings，每阶段用 `createTownRng(effectiveSeed + ":" + 阶段名)` 独立派生随机流。
3. **验证**（`validateTownDraft`，collect-all，Spec §6）：道路图节点从主城门 BFS 全可达；建筑入口在 footprint 边界、门前格为道路且道路层可达主城门；footprint 两两不相交、不压道路/水域/城外；非 reserved 地块临街 ≥ 2 格。issue 码 6 种：`ANCHOR_UNREACHABLE` / `ENTRANCE_MISSING` / `ENTRANCE_UNREACHABLE` / `BUILDING_OVERLAP` / `BUILDING_ON_FORBIDDEN_TILE` / `PLOT_FRONTAGE_TOO_SMALL`。
4. **修复**：建筑类 issue 按「换入口方向 → 开 1–3 格门前巷道 → 舍弃泛化建筑」次序；临街不足降 reserved；剧情建筑不可舍弃。**修复预算按验证轮次计 ≤ 20 轮**（一轮批量处理当轮全部可修 issue，非按建筑逐个计数），每轮修复后重验。
5. **重试**：修复无解时以 `hashTownSeed(seed + "#retry" + n)` 派生 seed 重跑整镇 ≤ 3 次；全败抛 `TownGenerationError`（携带 issue 列表）。
6. **剧情建筑齐全性**：放置阶段无可用地块时静默跳过，编排层 `collectStoryIssues` 检查缺失并**复用 `ENTRANCE_MISSING` 码**（`buildingId` 用 `requiredBuilding.key`，无专用「建筑缺失」码）；该问题局部不可修，直接触发 seed 变体重试。
7. **确定性**：生成器为纯函数，随机只来自 seed（FNV-1a + mulberry32，见 `townRandom.ts`），同 seed 输出深度相等；无 `Math.random` / `Date` / IO / env。

网格合法域 24–40（方形），默认 32×32；生成器版本 `TOWN_GENERATOR_VERSION = "town-gen-0.1.0"` 写入快照。

## 当前实现现状

- **领域类型**（`src/game/domain/townSnapshot.ts`）：`TileType`（12 种瓦片）、`TownSemanticPlan`、`RoadNode`/`RoadEdge`、`TownBlock`/`TownPlot`/`TownBuilding`、`TownGrid`（行优先扁平数组，索引函数 `tileIndex`）、`TownSnapshot`（含 `validation: { valid: true, repairCount, retryCount }`，验证失败不产出快照）。
- **生成器**（`src/game/gameplay/rpg/town/`）：门面 `index.ts` 只导出 `createFallbackTownPlan` / `createTownRng` / `generateTown` / `TownGenerationError` 及相关类型；内部工具（`hashTownSeed`、`validateTownDraft`、terrain/anchors/roads/blocks/buildings 各阶段）不出门面，deep-import 被 `dependencyBoundaries.test.ts` 的 `TOWN_DEEP_IMPORT` 规则拦截。
- **application 门面**（`src/game/application/townDemo.ts`）：`generateTownDemoView(seed)` 纯同步——seed trim 后非空且 ≤ 64 字符，否则 `INVALID_SEED`；`TownGenerationError` → `GENERATION_FAILED`（不外泄 issue 细节）；成功返回 `TownDemoView`（snapshot + 7 项 stats 投影）。
- **生图 port**（`src/game/application/townAssets.ts`）：只有类型 + `createUnavailableTownIllustrationSource()` 工厂，恒 `not_requested`、不含 `assetUrl`；不读文件/env/网络。`queued`/`generating`/`ready`/`failed` 仅是类型预留，无实现路径。
- **demo 页面**（`/town-demo`，静态路由，无环境门禁）：seed 输入 + 「生成」+「随机种子」（`crypto.randomUUID` 仅 UI 层换 seed 文本）；统计行（建筑/剧情建筑/地块/占用/预留/修复/重试）；SVG 逻辑地图（每格 12px rect 按 TileType 着色，建筑可点击/键盘可达，剧情建筑高亮描边）；「显示地块边界」「显示路网节点」两个默认关闭的调试开关；点击建筑打开档案面板（名称/类型/区域/命名状态/占地/入口方位 + SVG 占位外观图 + warning Tag「AI 生图未接入（预留接口）」）。
- **与 Spec §7 的实现差异**：未实现 hover 提示、图例、街区边界开关、广场/水井图标与「生成耗时」统计项（统计行改为展示修复/重试次数等 snapshot 可对账数字）。

## 主循环实装（S1–S8）

- **地点分级**：`LocationDefinition.scale?: "scene" | "town"`（缺省 `"scene"`，零迁移）；`locationScaleOf(location)` helper 。`GameState` 新增 `towns: readonly TownRuntimeState[]` 与 `townGeneration: TownGenerationState`。
- **离线模式**：`performAction` move 到 town 地点时同步调 `ensureTownRuntime` 直接产出 `TownRuntimeState`（`planSource: "offline"`）+ `town_plan_generated` 事件，无 pending 态。
- **AI 模式**：move 到 town 地点时写 `townGeneration = { status: "pending" }`；客户端轮询 `POST /api/game/town/ensure` 驱动 `generatePendingTownPlan`（镜像 Phase 10 narrative 的 pending/ensure/CAS 模式），`planSource: "generated"`；耗尽降级 `"fallback"`。
- **语义投影**：`projectTownSemanticView`（或 application `projectTownLayerView`）将快照反向投影为确定性语义句子（建筑九宫方位/邻近关系，如“铁匠铺位于大石镇北侧”）；经 `toTownSpatialContext` 注入导演/编剧上下文（`DirectorContext`/`SceneScriptContext` 的 `townSpatial?`），使 AI 叙事可引用位置关系（不含坐标/seed）。
- **第三层入口 = 纯 UI 导航**：点击剧情建筑打开该地点既有场景视图（建筑↔NPC 经 `story_npc_<npcId>` key 反查绑定）；本阶段不新增 `enter_building` intent、不改 GameState 位置指针粒度。`TownLayerScreen` 默认开启 `TownMapSvg` 的 `showAiBuildingArt`，把 demo 预生成的 8 张建筑俯视贴图（`public/assets/town-experiment/<buildingType>.jpg`，与 8 种 `TownBuildingType` 一一对应）叠到 footprint 上作占位，待正式生图管线（`TownIllustrationSource`）接入后替换。
- **开局契约**：`scenarioResponseFormat.ts` 的 `LOCATION` 增 `scale` 枚举；`scenarioPrompt.ts` 指导大型聚落标 town（≤ 2 个）、小场景标 scene；缺失由机械修复补 `"scene"`。`sqliteGameRepository` 的 `withTownDefaults` 为旧存档补 `towns: []` + `townGeneration: idle`，不升 schema 版本、不回写。

## 修改注意事项

- **生成器必须保持纯函数**：随机只能来自 seed 派生的 `TownRng`，禁止 `Math.random` / `Date` / IO / env；任何算法或参数改动都会改变同 seed 输出，必须先跑 1000 seed 批量回归，且**断言失败先修生成器，不放宽断言**。
- **算法/参数演进时提升 `TOWN_GENERATOR_VERSION`**，便于快照回归钉值。
- **不改 `createFallbackBlueprint.ts` 的 RNG**：`townRandom.ts` 是有意复制其私有 FNV-1a/mulberry32 实现（不 import 该文件），避免波及主循环的钉值 fixture。
- **AI 生图接入（若未来做）**：实现同一 `TownIllustrationSource` 接口替换 unavailable 工厂，并升级 `TOWN_ASSET_CONTRACT_VERSION`；在此之前 UI 不得出现任何网络图片。
- town 内部模块只能经 `@/game/gameplay/rpg/town` 门面消费；新导出需同步考虑 `dependencyBoundaries.test.ts`。
- 接入主循环后：**AI 永不碰坐标**——`town-plan-v1` 契约只输出封闭词汇语义规划（主题/区块/必备建筑/偏好方位），几何由 `generateTown` 编译；候选必经 `validateTownPlanCandidate` 机械修复 + 一次 `generateTown` 编译验证，耗尽有界尝试（≤ 3 次）后降级为离线 plan（`planSource: "fallback"`）。
