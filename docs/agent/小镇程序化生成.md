# 小镇程序化生成

## 职责

小镇系统为 `scale: "town"` 地点提供确定性几何、剧情建筑 slot 和 NPC 绑定。它只生成和投影城镇空间，不负责地图地点规则、任务裁决或叙事 provider。

## 当前契约

- `createTownRuntime` 只保存 `locationId`、seed、generator version 和 slot 状态；几何由 `generateTown` 按 seed 在读模型中重建。
- 生成阶段为 terrain、anchors、roads、blocks/plots、buildings；验证道路连通、入口可达、footprint 不重叠且不压非法瓦片，失败时在固定预算内修复或换派生 seed。
- 随机只来自 `src/game/gameplay/rpg/town/townRandom.ts` 的 seed 派生 RNG；生成器不使用 AI、网络、时间、IO 或 `Math.random`。
- 开局预分配 story-required 建筑 slot，焦点 NPC 和后续具象化 NPC 运行时绑定第一个空闲 slot；绑定不改变几何或 building ID。
- `town_building` 提案复用当前城镇 slot，并可设置建筑展示名；`world` placement 才铸造世界地图地点。无 `/api/game/town/ensure`。
- `TownView` 只暴露快照、展示标签和可进入建筑；已绑定 slot 的在场 NPC 正常生成入口，旧状态或读模型发现未绑定的在场 NPC 时会确定性补配空闲剧情 slot，满槽时焦点 NPC 可借用剧情建筑入口。仍不暴露 seed、空闲 slot、隐藏 NPC、未批准地点或生成器内部；`isCurrentFocus` 只标记真实焦点建筑。
- 普通建筑进入是 UI 导航；当前事实目标建筑可消费已有 `arrivalChoiceToken`，用于规则型自动揭示，不新增建筑 action。
- 屋顶展示由 `TownLayerScreen` 从壳层接收 `gameType`，经 `ContentAssetSvgImage` 渲染，`error` 后显式回退 `TILE_FILL`；`isUnexploredPlaceholder` 先于解析，地图几何与规则不变。图片合同见 [图片展示框架](./图片展示框架.md)。

## 必要流程

```text
town location
  → createTownRuntime / generateTown(seed)
  → bindNpcToTownSlot
  → buildTownView
  → TownLayerScreen / TownMapSvg
  → 普通建筑导航或目标入口 token
```

城镇几何与剧情建筑是空间层；地图旅行由地图 read model 与规则行动负责，NPC 对话由对话覆盖层和 `performTurn` 负责。
