# 中篇 RPG Chrome 真机完整剧情记录

> 测试日期：2026-08-13
> 测试分支：codex/real-browser-playtest
> 测试工作树：.worktrees/real-browser-playtest
> 测试方式：Chrome 用户浏览器真机连接，只通过 UI 新建游戏和提交行动
> 测试局：全新武侠 / 中篇 / 小说 / 黑暗 / 冷静 + 多疑

## 1. 测试角色与开局输入

- 玩家：顾沉舟
- 身份：被逐的镖师
- 角色简介：曾负责押送一支失踪的镖队，唯一留下的线索是一枚带血的铜铃。冷静，习惯从细节判断人心，不愿再让无辜者替自己承担后果。
- 世界前提：九州镖局与地方门派共同维持商路，近来失踪的镖队越来越多；官府把案子归为山匪所为，但每个现场都留下同样的血铜铃。
- 故事开端：雨后的黄昏，顾沉舟带着那枚血铜铃走进青石镇，镇口的缉凶告示上画着失踪镖队领队的脸，而落款却是三年前已经死去的自己。
- 选择的性格：冷静、多疑。

## 2. 序幕与可见世界

序幕实际显示：

> 雨刚停，青石镇的青石板路还泛着水光，镇口的缉凶告示被风掀起一角，露出画上那张熟悉的脸——那是失踪镖队的领队，落款却写着顾沉舟的名字，一个三年前就该死了的人。你摸了摸怀中那枚带血的铜铃，铜锈与血腥气混在一起，像一句迟来的质问。

初始状态：

- 当前地点：青石镇
- 初始目标：与老陈交谈
- 初始建筑：福来酒楼
- 初始焦点 NPC：老陈，镇口更夫
- 初始旁注：青石镇是被商路穿过的边境小镇。雨后黄昏，镇口老槐树滴着水，缉凶告示在风中摇晃，街上行人稀少，几家店铺亮起昏黄的灯火，远处传来几声犬吠；阴影里似乎有什么在注视这里。
- 老陈初始对白：

> 昨夜镇外的风声不对。你想问哪一段，我只说自己亲眼见到的。

初始焦点对话给出两类固定选择和自由输入：

1. 玩家口吻对白：回应老陈：“我先相信你，但请把知道的说清楚。”
2. 非对白动作：默默不作声，先观察四周
3. 自由输入：输入回应……

## 3. 逐回合剧情记录

本局共完成 20 个行动回合，经历五幕主线，最终到达结构化结局。场景生成期间通常等待约 30 秒；生成模态会锁住底图操作，期间没有通过重复点击绕过等待。

### 回合 0：序幕 / 青石镇

- 行动：新建中篇游戏，阅读序幕并开始冒险。
- 叙事核心：顾沉舟带着血铜铃进入青石镇，在告示上看到已死的自己，旧镖队失踪案与“自己已死”的矛盾同时出现。
- 任务：雨夜问路，目标是与镇口更夫老陈交谈。
- 评价：开幕动机清楚，血铜铃、失踪镖队、死亡告示三条线索能够自然地推动玩家去问路。

### 回合 1：老陈 / 镇口问路

- 行动：选择玩家口吻对白：回应老陈：“我先相信你，但请把知道的说清楚。”
- 可见 NPC：老陈，镇口更夫。
- 玩家选项同时提供：玩家口吻对白、默默不作声，先观察四周、自由输入。
- 结果：场景正常提交并开始编排下一幕。
- 目标变化：与老陈交谈 → 与顾砚交谈。
- 世界变化：青石镇新增铁匠铺，顾砚作为旧案传讯人出现。
- 叙事评价：更夫提供“亲眼见到的风声”作为调查入口，顾砚作为下一棒传讯人，因果方向正确；但当时目标只显示人物名，没有同时显示新地点，容易让玩家不知道需要离开当前建筑。

### 回合 2：顾砚 / 铁匠铺首次检查

- 行动：进入铁匠铺。
- 可见 NPC：顾砚，旧案传讯人。
- 可见物品：染血腰牌。
- 可见敌人：黑衣追兵。
- 顾砚对白：实际 UI 仍显示与前一场相同的通用固定对白选项：回应顾砚：“我先相信你，但请把知道的说清楚。”；另有默默不作声，先观察四周和自由输入。
- 非阻断问题：固定对白选项对不同 NPC 文案相同，玩家口吻不够像顾沉舟，也没有把顾砚的“线索/传讯”身份写进选择。

### 回合 3：顾砚 / 自由输入阻断

- 行动：自由输入“你说的旧案，是不是和失踪镖队有关？我手里有一枚带血铜铃。”
- 实际结果：UI 立即显示“行动被拒绝。”
- 影响：阻断了玩家在新地点第一次直接向目标 NPC 发问，且当时不能继续用期望的自由对白完成这一轮。
- 即时处理：停止继续推进，定位到 performTurn 的自由文本校验只接受 currentScene.event.kind === dialogue，没有承认“travel/observe 场景已经显示目标 NPC 台词”的状态。
- 修复：增加 focusedNpcForFreeText，当当前主线目标是当前地点的 talk NPC，且 ready 场景的 NPC 台词与目标匹配时，允许绑定该 NPC 的自由输入；补充 application 回归测试。
- 继续测试：为保留主线推进，使用已显示的非对白选择，进入下一回合。

### 回合 4：顾砚 / 非对白动作

- 行动：默默不作声，先观察四周。
- 结果：回合正常提交，进入下一轮编排；这证明动作型选项不是本地按钮，而是正式行动，能推进回合和场景。
- 目标：转向与苏绾交谈。
- 地图：新增可达地点断碑谷。
- 非阻断问题：目标文字仍只显示与苏绾交谈，没有直接提示“前往断碑谷”，玩家需要先返回地图才能推断下一步。

### 回合 5：苏绾 / 断碑谷自由对白回归

- 行动：进入断碑谷，等待新场景编排完成后，自由输入“你说的证据，是不是和失踪镖队有关？我带来了染血腰牌。”
- NPC：苏绾，失踪镖队幸存者。
- 可见物品：断裂镖旗。
- 直接对白：

> 别急着问镖队，先让我确认你手里有没有能对上旧案的证据。

- 固定选项：
  - 玩家口吻对白：当时仍为通用的回应苏绾：“我先相信你，但请把知道的说清楚。”
  - 非对白动作：不再追问，离开这里
  - 自由输入
- 结果：修复后的自由输入正常接受，回合从 4 推进到 5，出现“正在编排下一幕”后成功写回；此前的拒绝没有造成重复回合或脏写入。
- 评价：这是本次阻断修复的浏览器真机回归证据；苏绾的角色对白已经承接失踪镖队和证物，方向合理。

### 回合 6：程砚秋 / 卷宗线索

- NPC：程砚秋，旧案卷宗相关人物。
- 场景：仍在断碑谷，新增程砚秋和残缺卷宗。
- 直接对白实际显示为：

> 你刚才问的“你说的证据，是不是和失踪镖队有关？我带来了染血腰牌”，我先说我确定的部分；你还想了解哪一段？

- 评价：台词形式上承接了玩家上一句，也已经超过单句确认；但这是下一位 NPC 复述上一位 NPC 对话的问题，像是把玩家原话跨角色转交，角色之间缺乏明确的“谁听见了什么”的叙事桥。
- 非阻断记录：在主流程中先保留，避免打断全局记录；后续修改为只有同一焦点 NPC 才引用玩家原话，新 NPC 改用角色身份和当前证物开场。
- 行动：选择固定玩家口吻对白，回合正常推进。
- 目标：转向陆归鸿交谈。

### 回合 7：陆归鸿目标交接 / 断碑谷

- 目标：与陆归鸿交谈。
- 现象：陆归鸿尚未在当前地点，地图行动栏可以看到黑水古道；但任务 HUD 仍没有将“前往黑水古道”与“交谈陆归鸿”合并展示。
- 评价：主线因果可以理解为“卷宗线索 → 终幕知情人”，但玩家路径提示弱，是非阻断的导航可理解性问题。
- 行动：拾取残缺卷宗。
- 物品描述：被撕去关键页的卷宗，剩下的印记仍能与缉凶告示互相印证。
- 旁注：获得物品“残缺卷宗”后，地点氛围出现断碑谷、荒碑、黑泥和拖拽车辙；主线推进度显示第 5 / 5 幕、进度 100%、剧情节奏“迎接高潮”。
- 发现：地点最近场景旁注出现“。。”重复句号，属于显示层小问题，后续统一修复。

### 回合 8：断碑谷探索

- 行动：探索断碑谷。
- 结果：探索回合成功，主线目标仍指向陆归鸿；没有产生脱离主线的隐藏状态。
- 评价：探索动作有正式回合记录，但可见的新信息较少，主要作用是让玩家确认车辙和环境压力。

### 回合 9–16：断碑谷战斗 / 灭口

- 行动：挑战灭口刺客。
- 敌人：规则实际生成两名敌人：夺旗客、灭口刺客。
- 战斗 UI：独立全屏战斗；己方/敌方阵营明确；显示回合、HP、EN、当前行动、攻击/技能/防御/撤退和战斗日志。
- 战斗过程：
  - 多次攻击灭口刺客，敌人分别以普通攻击和技能反击。
  - 使用技能攻击夺旗客。
  - 再攻击夺旗客，最终击败两名敌人。
- 结果：第 8 个战斗行动后胜利，顾沉舟剩余 HP 18；地点旁注记录“与灭口刺客的战斗以胜利告终”。
- 评价：战斗对象没有凭空出现，夺旗客与灭口刺客共同阻止卷宗追查，和“灭口”任务语义吻合。战斗反馈、伤害日志和敌我阵营清楚。

### 回合 17：战斗后刷新恢复

- 行动：刷新 Chrome。
- 结果：等待加载后回到世界地图；回合号、目标与陆归鸿交谈、地点关系和战斗结束状态保持一致。
- 地图可见：前往青石镇、进入断碑谷、前往黑水古道。
- 评价：战斗写回与刷新恢复正常，没有丢失胜利状态。

### 回合 18：前往黑水古道

- 行动：从地图选择前往黑水古道。
- 结果：等待场景编排完成后进入黑水古道。
- NPC：陆归鸿，旧案知情人。
- 可见物品：盟誓铁印。
- 直接对白：

> 我手里的盟誓铁印能把最后一页卷宗钉在真相上；你若真要查下去，我就不再隐瞒。

- 固定选项：通用玩家口吻对白、不再追问，离开这里、自由输入。
- 特殊操作：对话面板提供把残缺卷宗交给陆归鸿。
- 评价：陆归鸿的盟誓铁印是终幕物证，能够把前面的残缺卷宗与幕后责任连接起来，剧情结构完整。

### 回合 19：交付残缺卷宗

- 行动：把残缺卷宗交给陆归鸿。
- 结果：回合成功编排，背包物品动作完成。
- 非阻断问题：交付后再次打开陆归鸿对话时，当前可见的直接台词仍基本保持不变，没有显式说出“卷宗已交付后，他如何核对印记”的即时反馈。
- 影响：不阻断终幕；玩家知道动作成功，但物品交付与对白承接还可以更明确。

### 回合 20：陆归鸿 / 终幕结局

- 行动：选择陆归鸿的玩家口吻对白。
- 中间状态：目标短暂显示暂无线索；场景行动中仍能看到探索、与陆归鸿交谈和挑战迷雾首领。
- 行动：挑战迷雾首领。
- 结果：没有再展开一场独立战斗，而是直接触发已满足条件的结构化结局。
- 结局：胜利。
- 结局名称：信任的黎明。
- 结局描述：

> 众人放下猜疑，以黑水古道的古老誓言为引，共同开启通往新纪元的道路，光明重新洒满古道。

- 结局后：界面只保留重新开始；刷新 Chrome 后仍恢复在该结局页，证明结局状态持久化。
- 评价：前置任务、物品、战斗和最终立场已经闭环；但挑战迷雾首领没有产生独立战斗，终幕的最终阻拦更多是结局条件而非玩家可操作的高潮，张力还有提升空间。

## 4. 主线因果链复盘

    血铜铃 + 死亡缉凶告示
      → 老陈的镇外风声
      → 顾砚的旧案传讯与染血腰牌
      → 苏绾的失踪镖队证词与断裂镖旗
      → 程砚秋的残缺卷宗与断碑谷车辙
      → 灭口刺客/夺旗客阻拦
      → 陆归鸿的盟誓铁印
      → 玩家交付卷宗并选择信任
      → 信任的黎明

这条链条的任务对象、地点、物品和敌人总体能相互解释，属于“能完整跑通、主因果成立”的中篇骨架。薄弱处主要在幕与幕之间的过渡句、玩家选项的角色口吻和终幕可操作高潮，不在任务目标本身。

## 5. 缺陷分级与处理

### 阻断问题：已即时修复并在同一局回归

| 编号 | 现象 | 处理 | 结果 |
|---|---|---|---|
| P-019 | 新地点的 travel/observe ready 场景已经显示目标 NPC，却拒绝绑定该 NPC 的自由输入 | performTurn 增加当前目标 NPC + 当前地点 + NPC 台词一致性校验；增加端到端回归测试 | 苏绾场景自由输入成功，主流程继续到终幕 |

### 非阻断问题：主流程结束后统一修复

| 编号 | 现象 | 修复 |
|---|---|---|
| P-020 | 目标只显示与苏绾交谈，不提示需要先前往断碑谷 | talk objective 在目标 NPC 不在当前地点时显示前往断碑谷，与苏绾交谈 |
| P-021 | 不同 NPC 共用我先相信你，但请把知道的说清楚，角色口吻单一 | 根据更夫、传讯人、幸存者、卷宗保管人、知情人等角色生成玩家第一人称对白选项 |
| P-022 | 新 NPC 复述上一位 NPC 收到的玩家原话，缺少角色间转述桥 | 只有当前 job NPC 与当前焦点 NPC 相同才引用玩家原话；换 NPC 时改用角色化开场和当前线索 |
| P-023 | NPC fallback 台词偏短，常只有一句 | 角色化开场增加第二句，直接对白各关系档位增加第二句承接或追问 |
| P-024 | 地点旁注偶尔出现重复句号 | 展示层合并连续中文句号 |
| P-025 | 交付残缺卷宗后 NPC 话术变化不明显 | 当前暂保留为低优先级文案增强项，未改变规则结果；需要更细的交付后上下文节拍 |

### 总评

本局已经达到“中篇主线可完整通关、因果链可理解、两类选项可用”的可玩状态。主要短板不是功能闭环，而是叙事表达：NPC 仍需要更多真正的来回对白、角色之间的明确接话、交付证物后的反应，以及一个可操作的终幕冲突。修复后，下一步优先级应是扩大角色化多轮对白模板和终幕动作节拍，而不是继续增加无关支线。
