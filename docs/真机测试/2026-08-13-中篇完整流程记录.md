## 剧情流程

> 记录格式：开幕 → 与谁交谈/选择什么 → 获得什么信息或物品 → 前往何处/调查什么 → 因为什么与谁战斗 → 战斗结果 → 幕交接 → 结局。

本轮使用过多局全新中篇存档进行黑盒回归；AI 开场 NPC 名称会变化，但修复后的剧情承接链固定为“上一幕线索 → 下一幕人物 → 可验证物品/威胁”。一次完整链路如下：

`序幕（沈青崖进入青石镇，看到与自己相似的缉凶告示） → 与开场 NPC（老陶/吴九）交谈，询问镇外陌生人 → 获得其关于旧案与镇外脚印的线索 → 与顾砚交谈，确认他是韩七留下的旧案传讯人 → 获得“染血腰牌” → 与苏绾交谈，承接失踪镖队线索 → 获得“断裂镖旗” → 与程砚秋交谈，确认其保管旧案卷宗 → 获得“残缺卷宗” → 灭口刺客与黑衣追兵出现 → 进入独立战斗场景，以攻击/技能/防御完成回合制战斗并击败敌人 → 回到场景并由 HUD 给出下一步 → 与程砚秋再次交谈后，目标转为终幕人物陆归鸿 → 在镇内高亮建筑/目标入口进入陆归鸿场景 → 选择“表示愿意支持陆归鸿”或“质疑陆归鸿” → 结构化信任/怀疑结局。`

其中“染血腰牌/残缺卷宗”在 Chrome 流程中实际拾取并出现在交谈上下文；“断裂镖旗/盟誓铁印”由中篇幕拍可选分支提供，是否在一局中出现取决于该局场景演化。

## 剧情与界面评价

### 已确认合理之处

- 开幕告示、旧镖局背景与青石镇线索建立主线动机；中篇每幕有明确承接人物和物件。
- 正式 API 行动期间使用模态并锁定底层操作，避免旧 revision 上继续点击。
- 战斗成为独立场景，左右阵营和回合反馈符合 RPG 预期，不再像地点页里的表单。
- 小镇采用“点击高亮建筑后查看建筑/NPC/进入”层级，右侧默认是地图提示而非开发状态列表。

### 已修复的不合理之处

- 已移除“临时会面”常驻侧栏，保留目标人物的建筑入口可达性。
- “当前剧情”只标注真实焦点建筑。
- 地点旁注不再承担任务目标和行动按钮；任务留在 HUD，行动留在底部行动栏。
- 终幕明确支持/质疑选择与信任/怀疑结局对齐。

### 后续建议

- 增加一轮专门的战斗撤退/失败后果 Chrome 流程，记录失败后的任务状态和敌人再次挑战表现。
- 在 Chrome 中切换窄屏视口，逐项回归背包、任务、日志和减少动态效果。
- AI source 若生成与 act beat 冲突的 NPC/物品/敌人，继续保持“承接上一幕线索”的审批约束。
